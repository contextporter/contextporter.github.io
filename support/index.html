ContextPorter Support

Help with provider sessions, page context, screenshots, files, permissions and shortcuts.

Before reporting a problem

  • Open chrome://extensions and confirm ContextPorter is enabled.
  • Open ContextPorter and check the active provider status.
  • Confirm you are signed in to the selected provider in the same Chromium profile.
  • If a shortcut does not fire, open chrome://extensions/shortcuts and confirm Chrome assigned it.
  • If persistent page buttons are enabled, verify Chrome still grants the requested site access.

Provider compatibility

AI providers can change their web clients and account/session requirements. ContextPorter surfaces provider-specific errors when a session needs to be refreshed or a capability is temporarily unavailable.

Privacy when reporting

Do not post passwords, session tokens, private page content, sensitive screenshots, or exported account data in a public issue.

Report an issue

Include the ContextPorter version, provider, what you expected, what happened, and the relevant website hostname if page capture is involved.
